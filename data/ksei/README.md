# KSEI shareholder lists

Save KSEI's monthly lists of shareholders above 1% here, as the PDFs IDX
publishes. The Ownership page reads every PDF in this folder: the latest one
names the owners of each IDX stock, and each earlier month adds what holders
bought and sold in between.

To get a list, open the [IDX announcements](https://www.idx.co.id/id/berita/pengumuman),
search for **Pemegang Saham di atas 1% (KSEI)**, and download the PDF for the
month. Any file name works. The app picks up a new file the next time the
page is opened.

The PDFs are kept in git, at about 7 MB a month. The `.cache` folder beside
them holds their parsed copies and stays out of git.
